# 砍价侠 KanjiaX

> 现有工具给数据，砍价侠给决策。

一个面向消费者的 AI 购物决策引擎。输入一个商品的多平台价格、历史价格与评论数据，输出一句话决策——**买 / 等 / 换**，且每条结论附带可验证的证据链。

## 为什么做这个

现有的比价工具（慢慢买、什么值得买等）只给数据，判断仍靠用户自己。砍价侠直接给决策，这是从「工具」到「Agent」的产品代际跃迁。

与同类项目相比，砍价侠补齐了三个关键模块：

| 能力 | 常见比价项目 | 砍价侠 |
|---|---|---|
| 输出 | 性价比评分 | 买 / 等 / 换 + 证据链 |
| 历史价格 | 多数没有 | 30 天走势 + 高低位判断 |
| 评论去水 | 几乎没有 | 可解释规则引擎 |

评论去水是这个细分里的公认空白——连 Mozilla 的 Fakespot 都已在 2025 年关停。砍价侠不追求高准确率，追求**每条判断能解释、能验证**。

## 快速开始

零依赖，纯 Python 标准库，clone 下来即可运行。

```bash
git clone https://github.com/jiaojiaosr4/kanjiax.git
cd kanjiax
python main.py
```

运行后生成 `report.html`，双击打开即可看到三个示例商品的完整决策卡。

## 示例输出

内置三个商品，分别演示三种决策：

- **降噪耳机** → 等（当前处于近 30 天高位，距最低点贵 13.6%，建议等年货节）
- **电动牙刷** → 买（接近历史最低，拼多多券后最便宜）
- **保温杯** → 换（30% 评论疑似刷单，真实差评指向保温差、异味，便宜也别买）

每张决策卡包含：决策结论、全网比价表、30 天价格走势图、评论去水结果、证据链。

## 决策引擎

### 评论去水（可解释规则）

检测两类刷单信号，规则全部可解释：

1. **模板话术检测**：好评同时包含「物流」+「质量 / 不错 / 好 / 满意」类高频词
2. **时间集中检测**：模板好评集中在 ≤3 天内批量发布

同时从真实差评（1-2 星）中提取质量缺陷关键词（保温、异味、漏水、材质、续航等），作为「换」决策的核心依据。

### 历史价格判断

以「距近 30 天最低点的距离」判断当前位置（大促低点会拉低均价，故不用均价做基准）：

- 当前价 ≥ 最低价 × 1.10 → 高位（建议等）
- 当前价 ≤ 最低价 × 1.05 → 低位（可入手）
- 否则 → 均值区间

### 决策优先级

1. 评论去水发现严重质量缺陷 → **换**
2. 当前价处于高位 → **等**
3. 当前价处于低位且评论正常 → **买**
4. 默认 → **买**（最便宜平台可入手）

## 数据说明

当前 `data.py` 中的商品数据为**演示用模拟数据**，用于展示决策引擎的完整能力。

正式版将通过数据源适配器接入真实数据：
- 淘宝联盟 / 京东联盟 / 多多进宝 官方 API（合规，顺便打通返佣闭环）
- 自建 SQLite 价格库（每日采集，借鉴 PriceDive 思路）

数据源适配器接口已在规划中，切换数据源时引擎与前端无需改动。
