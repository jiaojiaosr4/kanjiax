# 砍价侠 KanjiaX

> 现有工具给数据，砍价侠给决策。

一个面向消费者的 AI 购物决策引擎。输入商品关键词或链接，输出一句话决策——**买 / 等 / 换**，且每条结论附带可验证的证据链。

## 两种运行模式

### 1. 示例数据模式（默认，无需配置）

```bash
python main.py
```

使用内置示例商品，演示决策引擎完整能力（比价、历史价格、评论去水、买/等/换决策）。生成 `report.html`，双击打开即可。

### 2. 联盟 API 模式（真实数据，需配置）

```bash
python main.py --tbk "耳机"
```

调用淘宝联盟官方 API，搜索真实商品并按划算度排序推荐。需先配置联盟凭证（见下文）。

## 配置淘宝联盟 API

联盟 API 返回真实商品价格、券后价、佣金率、销量，合规稳定。

1. 注册阿里妈妈账号（pub.alimama.com）并实名认证
2. 媒体备案（类型选「导购媒体」，公众号/小红书均可）
3. 创建应用，获取 `AppKey` 与 `AppSecret`
4. 获取推广位 PID（格式 `mm_账号_媒体_推广位`），取末段数字作为 `adzone_id`
5. 复制 `config.example.json` 为 `config.json`，填入三项凭证

或通过环境变量配置：

```bash
export TBK_APP_KEY="你的AppKey"
export TBK_APP_SECRET="你的AppSecret"
export TBK_ADZONE_ID="你的推广位ID"
```

配置后 `python main.py --tbk "关键词"` 即可搜索真实商品。

## 决策引擎

### 评论去水（可解释规则）

检测两类刷单信号，规则全部可解释：

1. **模板话术检测**：好评同时包含「物流」+「质量 / 不错 / 好 / 满意」类高频词
2. **时间集中检测**：模板好评集中在 ≤3 天内批量发布

同时从真实差评（1-2 星）中提取质量缺陷关键词（保温、异味、漏水、材质、续航等），作为「换」决策的核心依据。

### 历史价格判断

以「距近 30 天最低点的距离」判断当前位置：

- 当前价 ≥ 最低价 × 1.10 → 高位（建议等）
- 当前价 ≤ 最低价 × 1.05 → 低位（可入手）
- 否则 → 均值区间

### 决策优先级

1. 评论去水发现严重质量缺陷 → **换**
2. 当前价处于高位 → **等**
3. 当前价处于低位且评论正常 → **买**
4. 默认 → **买**（最便宜平台可入手）

### 划算度评分（联盟模式）

对搜索返回的多个真实商品，按以下权重计算划算分排序：

- 券后折扣力度 40%
- 销量验证 40%
- 佣金率 20%

## 项目结构

```

├── engine.py              # 决策引擎：比价 + 历史价 + 评论去水 + 决策 + 搜索排序
```

## 关于爬虫

本项目不采用爬虫作为数据源。原因：国内电商对 headless 浏览器有强反爬（实测京东对 headless 返回首页而非商品页），爬虫脆弱且存在合规风险。走联盟官方 API 是合规、稳定的路径，顺便打通返佣商业闭环。
